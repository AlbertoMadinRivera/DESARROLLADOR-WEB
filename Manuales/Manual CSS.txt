=========================================
REGLAS BÁSICAS DE CSS (GUÍA RÁPIDA)
=========================================

1. SELECTOR DE ETIQUETA
-----------------------
Aplica estilos a todas las etiquetas HTML indicadas.

p {
    color: blue;
}

h1 {
    text-align: center;
}

2. SELECTOR DE CLASE
--------------------
Se utiliza con el atributo class.

.mi-clase {
    color: red;
}

HTML:
<p class="mi-clase">Hola Mundo</p>

3. SELECTOR DE ID
-----------------
Se utiliza con el atributo id.

#encabezado {
    background-color: black;
    color: white;
}

HTML:
<h1 id="encabezado">Título</h1>

=========================================
EJEMPLO COMPLETO
=========================================

.card {
    width: 300px;
    padding: 20px;
    margin: 20px auto;
    background-color: white;
    border: 1px solid #ccc;
    border-radius: 10px;
    text-align: center;
    box-shadow: 0px 5px 15px rgba(0,0,0,0.2);
}

.card h2 {
    color: navy;
}

.card button {
    background-color: royalblue;
    color: white;
    border: none;
    padding: 10px;
    cursor: pointer;
}

.card button:hover {
    background-color: darkblue;
}

=========================================
UNIDADES MÁS UTILIZADAS
=========================================

px   = píxeles
%    = porcentaje
em   = relativo al elemento padre
rem  = relativo al tamaño raíz
vw   = ancho de ventana
vh   = alto de ventana

Ejemplo:
width: 50%;
font-size: 1.2rem;
height: 100vh;
