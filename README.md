# 📖 Acerca del Proyecto

Este repositorio documenta mi proceso de aprendizaje en desarrollo web Full Stack mediante la construcción de ejercicios, prácticas y proyectos integrando tecnologías fundamentales para la creación de aplicaciones web modernas.

Actualmente estoy recorriendo un camino que abarca desde la estructura de páginas web estáticas hasta la implementación de aplicaciones dinámicas con bases de datos y lógica de negocio del lado del servidor.

Las tecnologías estudiadas son:

- HTML5
- CSS3
- JavaScript
- AJAX
- PHP
- MySQL

---

# 🎯 Objetivos

Este proyecto tiene como finalidad:

- Comprender la estructura semántica de HTML5.
- Diseñar interfaces modernas utilizando CSS3.
- Desarrollar lógica interactiva con JavaScript.
- Implementar comunicación asíncrona mediante AJAX.
- Crear aplicaciones backend utilizando PHP.
- Gestionar información mediante bases de datos MySQL.
- Aplicar buenas prácticas de programación.
- Integrar frontend y backend dentro de proyectos Full Stack.
- Construir un portafolio profesional de desarrollo web.
