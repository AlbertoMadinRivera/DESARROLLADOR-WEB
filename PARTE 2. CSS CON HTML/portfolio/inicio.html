Sobre el proyecto

Actualmente la tecnología ha liminado las barreras geográficas, permitiendo a desarrolladores y analistas colaborar con empresas de cualquier parte del mundo de manera remota. Áreas como el desarrollo Front-End, encargado de la interfaz visual mediante tecnologías como HTML, CSS y JavaScript, y el desarrollo Back-End, enfocado en la lógica, procesamiento de datos y servicios utilizando herramientas como Python y bases de datos, ofrecen amplias oportunidades laborales internacionales.

Asi mismo, tecnologías especializadas como Shiny para R permite la creación de aplicaciones web interactivas orientadas al análisis de datos y la inteligencia de negocios. El objetivo es continuar fortalenciendo las habilidades de técnicas en desarrollo web, programación y análisis de datos para participar en proyectos globales, colaborar con equipos multidisiplinarios y contribuir para organizaciones de soluciones digitales innovadoras que generen valor para organizaciones de distintos sectores

Este portafolio documenta mi proceso de aprendizaje, los proyectos que desarrollo y las herramientas que utilizo para prepararme como profesional capaz de desempeñarse en entornos remotos, ya sea formando parte de equipos internacionales o desarrollando soluciones de manera independiente como freelancer. Cada proyecto representa un paso más hacia la consolidación de una carrera orientada a la innovación, la automatización, la visualización de datos y el desarrollo de programación orientada a lenguajes de procesamiento natural.
